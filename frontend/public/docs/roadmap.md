# Roadmap

Rheonic is actively evolving beyond the current MVP. The focus is to expand runtime protection while keeping setup simple and behavior predictable.

## Planned Improvements
- **Model downgrade actions**: route protected requests to safer fallback models when policy allows it.
- **Cached response flows**: return cached or fallback responses for selected protected scenarios.
- **Stronger rate limiting**: extend runtime controls beyond the current request and token caps.
- **More policy actions**: add richer enforcement options and tuning presets for different workloads.
- **Better analytics**: provide deeper trend views and longer-horizon visibility for protect and incident behavior.

## Longer-Term Areas
- additional anomaly families,
- more provider wrappers,
- stronger cost and reconciliation workflows,
- broader multitenancy and workspace controls.

## Product Direction
The product direction remains the same:
- detect costly LLM runtime failures early,
- give teams clear evidence in the dashboard,
- add practical controls that can be rolled out safely over time.
